# F450 PID vs Linear MPC Web Poster

Static single-file web version inspired by the dark portfolio screenshots.

## How to use
Open `index.html` in any browser. No build step or internet connection is required because the F450 image is embedded directly into the HTML.

## Content note
The Results/Evaluation Metrics section intentionally uses `TBC` placeholders because the supplied draft paper still has results pending.

- Hero / project identity

- Technical problem and research gaps

- Evaluation metrics table
