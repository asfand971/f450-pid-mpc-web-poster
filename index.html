Abstract

Shared plant. Shared mission. Fair comparison.

The study uses the same nonlinear quadrotor model, mission profile, payload-release disturbance and logging pipeline for both controllers, so observed differences can be attributed to controller architecture rather than test setup.

/ Research Aim

Compare controller behaviour during delivery-critical payload transition.

Evaluate whether the predictive and constraint-aware structure of Linear MPC provides measurable advantages over a practical cascaded PID baseline for a low-cost F450 platform.

/ Platform

HAWK'S WORK F450 reference airframe.

Representative low-cost Pixhawk-style quadrotor with limited actuator and payload margins, making post-release altitude stability a controller-critical test.

/ Output

MIL framework before SIL, HIL and flight validation.

The web poster keeps numerical results marked as TBC until final simulations populate settling time, overshoot, error and control-effort values.

Technical Problem

Payload release is not a passive mission step.

At the release point, total mass changes suddenly. The hover equilibrium shifts and the quadrotor may overshoot, oscillate or drift if the controller cannot reject the disturbance smoothly.

G1

Fair comparison gap

PID and MPC studies often use different trajectories, constraints, models or assumptions.

G2

Payload transition gap

Delivery release is often treated weakly despite causing a discrete change in vehicle dynamics.

G3

Low-cost platform gap

Educational drones differ from a payload-carrying F450-class research vehicle.

G4

Validation gap

MIL must be structured so it can progress into SIL, HIL and physical flight tests.

/ Controller-Critical Event

Before release: heavier vehicle. After release: thrust excess.

The loaded vehicle requires greater hover thrust. When the payload is released, the same thrust demand may briefly exceed the new equilibrium requirement, creating altitude overshoot and recovery transients.

Controller Design

Reactive baseline vs predictive alternative.

The study does not claim a new controller. It asks whether Linear MPC gives measurable performance gains over a practical cascaded PID baseline under the same payload-transition mission.

/ Baseline

Cascaded PID

Hierarchical inner attitude loops and outer altitude/position loops. Practical, transparent and computationally light, but fundamentally reactive.

01 Inner attitude/rate stabilisation
02 Outer altitude and waypoint tracking
03 Fixed gains with anti-windup handling
04 No explicit prediction or constraint optimisation
/ Alternative

Linear MPC

Uses a hover-linearised plant to predict future behaviour over a finite horizon and optimise control moves subject to defined constraints.

01 Prediction horizon and control horizon
02 Actuator-aware optimisation
03 Penalises tracking error and control effort
04 Higher modelling and compute requirements

Implementation

MATLAB mission update excerpt.

The important implementation idea is writing custom mission waypoints into the model’s baseMission structure in-place, preventing the package-delivery example from falling back to its default mission.

F450_MIL_MASTER_v5.m
%% Vehicle + payload physics
mass_total    = 2.476;
T_motor_max   = 9.81;
rpm_loaded    = 8500;
omega_max     = rpm_loaded * 2*pi/60;

% The model reads ONLY from baseMission in the data dictionary.
m = getValue(getEntry(sec, 'baseMission'));
home_N = m(1).position(1);
home_E = m(1).position(2);
home_alt = -15; % NED: -15 = 15m above ground

mission_positions = [
  home_N,      home_E,      home_alt;  % takeoff
  home_N+50,   home_E,      home_alt;  % waypoint
  home_N+50,   home_E+50,  home_alt;  % delivery leg
  home_N,      home_E+50,  home_alt;  % recovery
  home_N,      home_E,      home_alt;  % return
  home_N,      home_E,      0          % land
];

for i = 1:numel(m)
  if i <= size(mission_positions,1)
    m(i).position = mission_positions(i,:);
    if i == 1; m(i).mode = 1; elseif i == size(mission_positions,1); m(i).mode = 4; else; m(i).mode = 2; end
  else
    m(i).position = [home_N, home_E, home_alt];
  end
end
setValue(getEntry(sec, 'baseMission'), m);
saveChanges(dd);
